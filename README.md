## 🚀 Key Features

1. **Specialized Intelligence Multi-Agent Roles**:
   - **`ScraperAgent`**: Scrapes and deduplicates reviews across 5+ global platforms.
   - **`AnalyzerAgent`**: Aspect-Based Sentiment Analysis (ABSA) and churn risk quantification.
   - **`InsightAgent`**: RICE score roadmap prioritization and executive strategic synthesis.
2. **Customer-Centric Innovation**: Directly converts raw customer friction into engineering-ready feature specifications.
3. **Interactive Studio**: Dark cyber-glassmorphic bilingual (English/Arabic RTL) dashboard with live review stream and RICE roadmap matrix.
